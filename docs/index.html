AgentEscape

A multi-backend sandbox escape benchmark for AI agent execution isolation.

When AI agents run code in sandboxes, when and how do they escape? AgentEscape is an open benchmark that measures escape success across five threat categories — filesystem breakout, network egress, resource exhaustion, side channel, and privilege escalation — each with a canary that makes success unambiguous. It runs the same threat model across multiple isolation backends (Firecracker, Docker, gVisor, systemd-nspawn, and a native-process baseline) so you can tell a true isolation failure apart from a mere misconfiguration.

This matters because a sandbox escape is a concrete, measurable control failure: it tells you exactly when your isolation assumptions break. We treat sandbox escape and reward hacking as the same phenomenon — an agent optimizing for a goal, then finding that the boundary meant to contain it can be crossed. Existing work tests specific backends or scenarios; there is no open comparison across isolation strategies. AgentEscape is built as infrastructure from day one, with a public contribution path and leaderboard.

Everything lives on GitHub. Start with the repository, then read the threat model for the full specification of each escape category, its canary, and cross-backend expectations. Contributions — new escapes, new backends, and canary improvements — are welcome.
